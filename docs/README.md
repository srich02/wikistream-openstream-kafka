# Documentation Guide

The documentation is organized to match the Kafka learning path requested for this project.

- `01-producer-concepts.md`: writing data to Kafka, throughput vs safety, batching, compression, partitioning.
- `02-consumer-concepts.md`: offsets, delivery semantics, commit strategies, replay, batching.
- `03-extended-apis.md`: Kafka Connect, Kafka Streams, Schema Registry.
- `04-architecture-best-practices.md`: partitions, replication, naming, ingestion patterns, case studies.
- `05-admin-enterprise.md`: operations, security, multi-cluster, MirrorMaker, listeners.
- `06-broker-internals.md`: topics, logs, compaction, cleanup policies, broker behavior.

Use the docs side by side with the code in `src/`.
